# PitWall AI Backend API Documentation

The PitWall AI Backend exposes a REST API powered by FastAPI. It serves predictions generated by our advanced tabular models.

## Base URL
`http://127.0.0.1:8000`

## Endpoints

### 1. Health Check
Checks if the API is running and responsive.

**GET** `/health`

**Response (200 OK):**
```json
{
  "status": "ok",
  "service": "PitWall AI Backend"
}
```

---

### 2. Predict Race
Generates predictions for a specific race weekend at a given stage.

**GET** `/predict/race`

**Query Parameters:**
*   `season` (integer, required): The season year (e.g., 2024). Must be between 2018 and 2030.
*   `round` (integer, required): The race round number (e.g., 6). Must be between 1 and 30.
*   `stage` (string, required): The point in the weekend. Must be either `pre_weekend` or `post_qualifying`.

**Example Request:**
```bash
curl "http://127.0.0.1:8000/predict/race?season=2024&round=6&stage=post_qualifying"
```

### Error Responses

**400 Bad Request** (Invalid Stage):
```json
{
  "detail": "Invalid stage 'mid_race'. Must be one of: ['pre_weekend', 'post_qualifying']"
}
```

**404 Not Found** (No data for season/round):
```json
{
  "detail": "No features for season 2024 round 99 stage pre_weekend."
}
```
